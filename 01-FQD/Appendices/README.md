The companion workbook is named `PQD-FH_01_Universal_FQD_Templates.xlsx` and contains the editable templates for Appendices A–I.

Appendices A, D.1 and G are also available as separate PDF forms with interactive fields for electronic completion. These forms complement the companion Excel workbook and can be downloaded from the same GitHub repository. Download a PDF and open it in a reader that supports interactive form fields; save completed forms as separate controlled project records.
