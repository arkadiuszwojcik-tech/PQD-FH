# FQD — Editable Appendices

Editable appendices supporting Module 01: Universal Final Quality Documentation (FQD) Procedure.

**Status:** The companion Excel workbook and fillable PDF forms A, D1 and G are available on `main`. No FQD release has been published yet.

## Available files

| File | Format | Revision |
| --- | --- | --- |
| [Universal FQD Templates — companion workbook](PQD-FH_01_Universal_FQD_Templates.xlsx) | Excel (.xlsx) | 1.00 |
| [Appendix A — Project Requirements](Fillable-PDF/PQD-FH_01_Appendix_A_Project_Requirements_Fillable_Rev1.00.pdf) | Fillable PDF | 1.00 |
| [Appendix D1 — Package Index](Fillable-PDF/PQD-FH_01_Appendix_D1_Package_Index_Fillable_Rev1.00.pdf) | Fillable PDF | 1.00 |
| [Appendix G — Readiness Checklist](Fillable-PDF/PQD-FH_01_Appendix_G_Readiness_Checklist_Fillable_Rev1.00.pdf) | Fillable PDF | 1.00 |

The workbook contains the editable appendices. The individual PDF forms provide an additional option for completing Appendices A, D1 and G. Download a PDF and open it in a reader that supports interactive form fields; save completed forms as separate project records.

## Downloads and revision compatibility

- The first planned published release is `FQD-v1.0` (Procedure Rev.1.0).
- Once published, use the release identified in your copy of the FQD procedure to obtain the corresponding appendices.
- Each release will list its included files and their revisions.
- Files on the `main` branch may change between releases.
