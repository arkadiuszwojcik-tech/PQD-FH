# FQD — Fillable PDF Forms

Interactive PDF forms supporting PQD-FH 01: Final Quality Dossier (FQD) Procedure.

Appendices A, D.1 and G are available as separate PDF forms with interactive fields for electronic completion. They complement the companion workbook, `PQD-FH_01_Universal_FQD_Templates.xlsx`.

| Appendix | Form | Template revision | Procedure revision |
| --- | --- | --- | --- |
| A | [Project-specific Requirements](PQD-FH_01_Appendix_A_Project_Requirements_Fillable_Rev1.00.pdf) | 1.00 | 1.00 |
| D.1 | [Universal FQD Package Index](PQD-FH_01_Appendix_D1_Package_Index_Fillable_Rev1.00.pdf) | 1.00 | 1.00 |
| G | [FQD Package Readiness Checklist](PQD-FH_01_Appendix_G_Readiness_Checklist_Fillable_Rev1.00.pdf) | 1.00 | 1.00 |

Download a form and open it in a PDF reader that supports interactive form fields. Save the completed form as a separate controlled project record. Adapt the blank templates to applicable project requirements and approval arrangements before use.

Files on `main` may change. See [revision compatibility and the fixed Rev. 1.00 template snapshot](../README.md#downloads-and-revision-compatibility). The formal `FQD-v1.0` release is planned for 06-Oct-2026 and has not yet been published.
